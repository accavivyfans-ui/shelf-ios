# 서재 (Shelf)

NAS의 Synology Drive 공유 폴더에 있는 PDF·EPUB을 애플 북스처럼 읽는 iPhone 앱.
StudyOS 웹 앱(Tailscale)과 읽은 쪽·형광펜·책갈피·읽은 시간을 주고받는다.

- 리더: PDF(넘기기/스크롤/두 쪽, 썸네일 스크러버, 목차, 페이지 그리드, 검색, 형광펜 4색·메모, 책갈피, 세피아/어두운 테마), EPUB(가로 페이지 넘김, 글꼴·크기·줄간격·여백, 목차, 전체 검색, 형광펜·메모)
- 서재: 지금 읽기 / 서재(과목별) / 기출(시험·연도·과목, 정답 자동 연결) / 전체 검색
- 빌드: GitHub Actions → `latest` 릴리스의 서명 안 된 IPA
